# duality
An open-source Android APK patcher/instrumentation toolkit powered by Frida Gadget.

# HOW TO USE:
We will go step by step for this tutorial.
1. Sideload duality on your device.
2. Open com.thaz.duality, or just duality.
3. Select your app that you want to "patch".
4. Press patch.
5. You should see that duality patched your app, try running a frida script in your patched application.

# CONGRATS!!!!!

You just patched an apk/app with duality!
